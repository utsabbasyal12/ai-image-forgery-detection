# AI Image Forgery Detection

A learning and research project exploring how image processing,
pattern recognition, machine learning, and deep learning can be used
to distinguish real images from AI-generated or manipulated images.

## Project Goals

- Understand digital image representation
- Explore image preprocessing
- Extract image features
- Build a machine learning baseline
- Build a CNN-based detector
- Evaluate precision, recall, F1-score, and accuracy
- Investigate model generalisation

## Dataset

Initial experiments will use the CIFAKE dataset.

The dataset itself is not stored in this repository.
